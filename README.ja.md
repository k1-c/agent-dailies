# agent-dailies

**コーディングエージェントが作った物を、その場で見て返すためのページ。**

エージェントが画像を描いたり、動画を撮ったり、音や 3D モデルを作ったりすると、たいてい新しい窓が開くか、worktree の奥のパスだけが残ります。そのたびに「開いて」と頼むことになります。agent-dailies は、エージェントが見せる物の置き場所を 1 つにします。開いたままのブラウザのタブに、作った物が上から順にその場で並び、案どうしは横に並び、消えずに残ります。

ページの上で、見せられた物に **OK**（か一言）で返し、エージェントの問い（「この 3 つのどれ？」「どのパターン？」や、項目の並んだ設計のレビュー）に、選んで **送る** を押して答えます。一言そえるのは任意です。それはエージェントに届きます。エージェントが手を止めて待っている間でも届くので、パスのコピーではなくページを通してレビューが回ります。

名前は、映画やゲームの制作で前日の成果をみんなで見て残す物を決める「デイリーズ（dailies）」から。

- **タブは 1 つで、その場で増える**: 新しい投稿はいちばん上に入ります。窓は開かず、フォーカスも取りません。ブラウザを開くのは、ページがどこにも開いていないときだけです
- **何でも見られる**: 画像と GIF、動画（くり返し・音なし・見えている間だけ再生。Ogg Theora のように今のブラウザが再生しない形式は、[ffmpeg](https://ffmpeg.org/) があれば 1 度だけ変換して流す）、音、GLB/glTF（[model-viewer](https://modelviewer.dev/) で回せる）、PDF、HTML、Markdown とテキスト
- **Issue とセッションごとの履歴**: サイドバーに リポジトリ → Issue（無ければブランチ）→ エージェントのセッション を新しい順に並べ、未読の点・件数・回答待ちの数を出します。選ぶとその分だけを表示し、題・ファイル名・Issue で検索もできます。Issue はブランチ名から拾います（`summ-239` → `SUMM-239`）
- **Devlog（制作記録）**: 見る窓とは別のタブです。作業が main にマージされたら（マージする前には残しません）、エージェントがふりかえって「何がどう変わったか・工夫したこと・苦労したこと・決めたこと」を記録します（見た目や手触り・音が変わったなら before/after も必ず。画像のほか、動きや音は動画で）。あとで `agent-dailies devlog summary` が、前回のアップデートからの記録・決めたこと・コミット・会話の記録（Claude Code が消す前に写しておく）を集め、次のアップデートのまとめの材料にします
- **Issue の概要を表示**: Issue の投稿の上に、題・状態・プロジェクト・説明を出します。中身は自分で決めたコマンド（Linear・GitHub など）で取るか、エージェントが書きます
- **見て選ぶ**: `agent-dailies ask` はファイル・複数のファイルからなるパターン・文を A・B・C… の選択肢にして尋ねます。1 つの物の OK を聞くときは、その物を選択肢の上に出します（`--about`）。項目の並んだレビュー表もまとめて出せます。答えるとエージェントが起きます。文だけで答えられる質問はターミナルで聞きます
- **ファイルごとにコメントできる**: ファイルが何枚もある投稿では、ファイルの下の吹き出しのボタン（か全画面）からそのファイルにだけ一言を書けます。そのファイルの下に並び、投稿の下の欄は投稿全体へのコメントになります
- **返事がエージェントに届く**: コメントを書くと `agent-dailies watch` が終わってエージェントが起きます。hook でも、止まる前と次のメッセージで渡します
- **ファイルを持ち出せる**: 画像はクリップボードにそのままコピーして、どこにでも貼れます。動画や 3D モデルはパスをコピーしてアップロードの画面に貼れます。元の名前のままダウンロード（投稿まるごとも）でき、デスクトップやフォルダへドラッグして保存もできます
- **残る**: ファイルは中身のハッシュでリポジトリの外に置くので、worktree を片付けても消えず、git も重くしません
- **キーで操作できる**: `j`/`k` 投稿、`h`/`l` ファイル、`o` OK、`c` ファイルに一言（`C` は投稿に）、`f` 全画面、`1`〜`9` 選ぶ、`y` コピー（`Y` はパス）、`d` ダウンロード、`[`/`]` サイドバーを移る、`/` 検索

## 入れ方

[Node.js](https://nodejs.org/) 22.6 以降が `PATH` にあればよく、ほかに入れる物はありません（npm のパッケージもビルドも要りません）。

### Claude Code

```text
/plugin marketplace add k1-c/agent-dailies
/plugin install agent-dailies@agent-dailies
```

プラグインがそのまま道具の全部です。Claude Code がこのリポジトリを取ってきて、プラグインの hook が中のコードを Node で動かし、セッションの始まりに `bin/` をエージェントのシェルの `PATH` に足します（`$CLAUDE_ENV_FILE`）。なのでエージェントはそのまま `agent-dailies show …` と打てます。いつどう見せるかのスキルと、ページのことを伝え、メディアを窓で開くのを止めて `show` を使わせ、コメントを渡す hook も入ります。

### 自分のシェルや、ほかのエージェントで

リポジトリをクローンして `bin/` を `PATH` に通します（`ln -s <clone>/bin/agent-dailies ~/.local/bin/`）。エージェントに渡す説明は `agent-dailies guide` で出ます。

## 使い方

エージェントが打ちます。

```sh
agent-dailies show render_a.png render_b.png --title "ライティング A / B" --note "B は補助光を落とした"
```

判断が要るときは、こう尋ねます。

```sh
agent-dailies ask "どの正面でいく？" a.png b.png --option "どれも違う。描き直す" --why "背面の形がいちばん近いのは B"
agent-dailies ask "どの配色？" --pattern "今の配色" c_front.png c_back.png --pattern "暖色寄り" w_front.png w_back.png
agent-dailies ask "このカットで上げる？" --about cut.mp4 --option "このままでよい" --option "直したい所がある"   # 1 つの物の OK を聞く
agent-dailies ask --file review.json      # 項目の並んだレビュー表（書き方はスキルに）
agent-dailies wait <post-id>              # 裏で待つ。答えがそろうと終わる
```

あなたはタブで見て、OK か一言で返し、問いに答えます。エージェントは次で読み返します。

| コマンド | エージェントに分かること |
| --- | --- |
| `agent-dailies context` | ページで選んでいる物（無ければいちばん新しい投稿）。ファイルのパス・答え・返事 |
| `agent-dailies wait <post-id>` | 投稿の問いが全部答えられる（かコメントが付く）まで待ち、答えを出して終わる |
| `agent-dailies watch` | このセッションの投稿にコメントが付くまで待ち、出して終わる。裏で走らせておくと、コメントでエージェントが起きる |
| `agent-dailies feedback [--since 2h] [--all]` | この worktree での採用・不採用・コメント |
| `agent-dailies list [--all]` | 最近の投稿 |
| `agent-dailies get <item-id> [--to PATH]` | 置いたファイル |

人が使うのは `agent-dailies open`（ページを開く）・`status`・`stop` です。

### Issue の概要

agent-dailies はどの課題管理にも直接はつなぎません。Issue を JSON で出すコマンドを、自分の設定ファイル `~/.config/agent-dailies/config.json` に書きます（`{key}` が Issue のキーに置き換わります）。

```json
{
  "projects": {
    "game-lab": { "issueCommand": "linear-tui issue show {key} --json" }
  }
}
```

投稿が Issue を名指すと、裏でこのコマンドを流して（同じ Issue は 30 分に 1 回まで）、題・説明・状態・URL・プロジェクト・マイルストーン・ラベルを記録します。読むのは自分の設定だけで、リポジトリの中の設定からコマンドが動くことはありません。コマンドを置かないときは、エージェントが `agent-dailies issue <KEY> --title … --description …` で書けます。

### ファイルの持ち出し方

| ページで | 手に入るもの |
| --- | --- |
| ⧉ コピー（`y`） | 静止画は画像そのもの（PNG）。チャット・Issue・投稿にそのまま貼れます。テキストは中身。動画・音・GIF・3D モデルはファイルのパス（ウェブのページからは、これらをファイルとしてクリップボードに置けないため）。アップロードの画面で `Ctrl+L` を押して貼り付けます。Shift を押しながら（`Y`）だといつもパス |
| ⤓ ダウンロード（`d`）・⤓ すべて | ファイル（投稿まるごとも）を元の名前で保存。Chrome のダウンロードの吹き出しから、ほかのサイトへそのままドラッグできます |
| ファイル名（か画像）をドラッグ | デスクトップやフォルダに落とすとファイルそのもの。ほかのページに落とすと、画像は画像、それ以外はリンクとして届きます |

### 使い分け

| 場面 | 使う物 |
| --- | --- |
| エージェントが作っている途中の物を見る | `show` |
| 見る物どうしの選択（どの絵にするか・見た目の OK・何を残すか） | `ask` |
| ほかの人が読む・あとまで残るページ（報告・共有する文書） | エージェントの文書やアーティファクト |
| 文だけで答えられる質問（どの方針か・はい / いいえ・名前・次に何をするか。設計の判断も） | ターミナル |

置き場所・環境変数・安全のための決まり・これからの予定（Cloudflare R2 でマシン間の同期。`wrangler login` のあと `agent-dailies init` だけで、サーバーを立てない）は [README.md](README.md) にあります。
